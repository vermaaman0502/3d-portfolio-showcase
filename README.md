# Aman Verma — AI Engineer Portfolio

A modern, interactive 3D portfolio website built with React, Three.js (React Three Fiber), and Framer Motion. Features a neural-network-themed design with scroll-synced 3D animations.

## 🔗 Live Demo

**[View Portfolio →](https://id-preview--cdbf24b2-7618-4bb8-b2e1-8fc29070ed7f.lovable.app)**

## ✨ Features

- **3D Neural Network Scene** — Interactive Three.js environment with animated neural nodes, data stream particles, and a pulsing AI brain sphere
- **Scroll-Synced Camera** — Camera moves through 3D space as you scroll through sections
- **Mouse Interaction** — Hover effects, parallax, and object rotation
- **Loading Screen** — Neural network initialization animation with progress indicator
- **Responsive Design** — Optimized for desktop and mobile
- **Dark AI Theme** — Deep blues, electric violet, and neural green palette

## 📂 Sections

- **Hero** — Name, title, and animated 3D background
- **About** — Bio, stats, and AI/ML focus areas
- **Projects** — AI-focused project cards (Workflow Automation, Agent Framework, Analytics Engine, Document Processor, LLM Fine-Tuning)
- **Skills** — Categorized tech stack with animated elements
- **Contact** — Get in touch section

## 🛠️ Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React, TypeScript, Tailwind CSS |
| **3D** | Three.js, React Three Fiber, Drei |
| **Animation** | Framer Motion |
| **Build** | Vite |
| **UI** | shadcn/ui, Lucide Icons |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
